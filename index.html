Sobre o projeto

Este projeto apresenta uma análise de dados climáticos do Brasil entre 2015 e 2024, utilizando Python para tratamento, análise e visualização dos dados.

A análise considera temperatura, chuva, umidade, velocidade do vento, eventos extremos e níveis de alerta.

Objetivos

  • Analisar os dados climáticos do Brasil.
  • Realizar a limpeza e preparação dos dados.
  • Criar indicadores climáticos.
  • Identificar padrões temporais e sazonais.
  • Comparar regiões e estados.
  • Analisar eventos extremos.
  • Apresentar os resultados por meio de gráficos.
  • Desenvolver um dashboard interativo.

Principais indicadores

Temperatura

Análise da temperatura média e sua evolução ao longo do período.

Chuva

Análise do volume de chuva ao longo do tempo e comparação entre estados.

Eventos extremos

Análise da ocorrência de eventos extremos durante o período estudado.

Umidade

Análise da umidade média presente nos registros climáticos.

Dashboard interativo

O projeto possui um dashboard desenvolvido com Streamlit, permitindo filtrar os dados por ano, mês, região, estado, cidade e nível de alerta.

Tecnologias utilizadas

  • Python
  • Pandas
  • Matplotlib
  • Seaborn
  • Streamlit
  • NumPy
  • GitHub
